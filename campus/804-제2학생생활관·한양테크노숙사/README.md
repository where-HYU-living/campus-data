## 1. 외관 메모 (사진 보고 정리)
- 전체 형태: 중앙 짙은 회색 코어(세로 유리 슬릿) 양쪽으로 날개가 벌어진 10층 판상형(ㄱ자/V자). 테크노숙사(7층)가 붙어 층마다 연결
- 층수·높이(눈대중): 지상 10층·지하 1층, 34.7m(대장). 8~10층은 면적이 줄어듦
- 지붕: 평지붕, 옥탑(물탱크·계단실·엘리베이터 기계실)
- 외벽 재질·색: 도장 — 상층 흰색(#E6E6E3), 저층 3개층 짙은 회색(#7C8086), 코어 회색(#6E7378)
- 창문 패턴: 층마다 가로로 늘어선 개별창, 층 사이 회색 수평 띠, 창마다 실외기
- 입구·계단: 도로 쪽 박스형 평캐노피('제2학생생활관') + 유리문, 낮은 계단과 경사로
- 특징(기둥, 간판, 조형물 등): 베이지 석재 문기둥과 접이식 철문, 곡면 흰 벽
- 주변(나무, 바닥, 광장): 앞마당 주차, 도로변 은행나무와 붉은 벽돌 화단 담
