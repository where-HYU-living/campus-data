- 층수·높이(눈대중): 약 10층 (대장/추천값은 표 0 참고)
- 지붕: flat, #cfd0cf — 난간·안테나 보임
- 외벽 재질·색: 도장(페인트) #ecebe8(창 사이 벽), 금속 패널 #6e7177(층마다 가로 띠·양 끝 계단실)

- 입구·계단: 서(본관 쪽 차로) — 노란 철골+유리 지붕 보행 캐노피 아래, 가로 루버 위 '동관 EAST BUILDING' 간판, 회전문/유리문 [1층] / 계단: 보이지 않음
