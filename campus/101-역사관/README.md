## 1. 외관 메모 (사진 보고 정리)
- 전체 형태: 4층 본체(앞에서 보면 좌우 대칭) + 가운데 2~3층 높이 6주 포르티코 + 양 끝 앞으로 살짝 나온 박공 날개. 북쪽 측면은 길을 따라 길게 3~4층, 동쪽 뒤로 유리 구름다리가 신본관과 연결
- 층수·높이(눈대중): 4층
- 지붕: mixed / 초록색 금속(동판풍) 경사 지붕 / 삼각 지붕창(도머) 여러 개, 양 끝 날개는 흰 삼각 박공+아치창, 작은 굴뚝
- 외벽 재질·색: 전체 베이지 화강석(#BFB59F), 정면 포르티코 기둥·박공·발코니 난간 도장(페인트)(#EDEBE3)
- 창문 패턴: 격자 개별창(세로로 긴 창, 층마다 규칙적), 창 위아래 다듬은 화강석 인방·창대
- 입구·계단: 서(광장·사자상 쪽) 포르티코 아래 현관, 앞에 넓은 화강석 계단; 북(측면 길) 측면 작은 출입구. 계단: 정면 가운데 넓은 화강석 계단(15~20단), 양옆 잔디 화단
- 특징(기둥, 간판, 조형물 등): 흰 원기둥 6개 + 부조 있는 삼각 박공, 벽에 'HANYANG UNIVERSITY HISTORY MUSEUM' 남색 배너, 검은 주철 가로등, 국가등록문화재(751호로 소개됨), 앞에 사자상(L01)
- 주변(나무, 바닥, 광장): 바닥 앞은 화강석 블록 광장·아스팔트 회차로, 북쪽은 아스팔트 길(노란 중앙선); 나무 정면 양옆 소나무·둥근 관목, 사자상 화단; 높낮이 남서쪽이 낮음 — 정면 계단으로 1층 진입, 북쪽 길은 오르막
