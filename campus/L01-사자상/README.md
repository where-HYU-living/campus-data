## 1. 외관 메모 (사진 보고 정리)
- 전체 형태: **밝은 회색 화강암**을 거칠게 깎은 사자 (청동 아님)
- 자세: 앞다리를 굽히고 가슴을 낮춘 **사냥 자세**, 엉덩이가 더 높음, 꼬리는 뒷다리 쪽으로 내려옴
- 머리: 고개를 들어 **정면(본관 바깥쪽)으로 돌림**, **입을 벌림**, 덥수룩한 갈기
- 받침: 울퉁불퉁한 **바위 받침** → 얇은 판석 → **2×2 돌블록 좌대** → 넓은 기단
- 명판: 좌대 정면 **검은 돌 명판**(글씨는 사진으로 판독 불가)
- 위치: **본관 정면 계단 왼쪽 앞** 작은 잔디밭, 잔디 위 **흰 원형 선**, 앞은 원형 회차로(아스팔트)
- (보강) **위치 정정**: 원기둥 6개 건물은 지금 번호로 **101 역사관(구본관)** 으로 보임 → 사자상은 **역사관 정면 계단 왼쪽 앞**. 102 신본관(시계탑 건물)은 그 뒤 북동쪽
- (보강) 바닥: 2026년 로드뷰 기준 서쪽 광장은 **회색 사각 화강석 블록 포장**(바닥에 HANYANG UNIVERSITY 글자), 회차로는 아스팔트 + 분홍 보행띠
- (보강) 주변: 굽은 **소나무** 여러 그루, 둥근 관목, 잔디 화단 가장자리 낮은 화강석 경계석
- (보강) 웹: 1965년 졸업생 졸업 기념으로 제작(영문 캠퍼스 소개 블로그)
