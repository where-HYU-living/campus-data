## 1. 외관 메모 (사진 보고 정리)
- 전체 형태: 길쭉한 판상형(OSM 윤곽 2개). 옆길 쪽 벽면이 층마다 살짝 꺾인 면으로 이어짐
- 층수·높이(눈대중): 지상 5층(+지하1, 공식). 높이 자료 없음
- 지붕: 평지붕으로 보임(사진에 안 보임)
- 외벽 재질·색: 도장 마감 — 밝은 회색(#C9CCCB)에 짙은 회색(#5E6268) 면, 1층 하부는 더 짙은 색(#3A3D42). 2013년 로드뷰는 흰색이었음
- 창문 패턴: 작은 개별창, 창 위 얕은 차양, 창마다 실외기
- 입구·계단: 주출입구는 사진에 안 보임. OSM 출입구 2곳(고도 약 30m)
- 특징(기둥, 간판, 조형물 등): 2톤 회색 도장, 어두운 하부
- 주변(나무, 바닥, 광장): 옆길(아스팔트 경사로) 맞은편에 담쟁이 덮인 자연석 축대, 건물 앞 관목
