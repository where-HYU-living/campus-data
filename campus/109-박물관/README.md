## 1. 외관 메모 (사진 보고 정리)
- 전체 형태: 5층 석조풍 상자에 세로로 긴 계단실·창 탑이 리듬 있게 돌출. 벽면 일부는 큰 부조 패널
- 층수·높이(눈대중): 5층
- 지붕: flat / 확인 못함(위쪽 처마형 돌출 테두리)
- 외벽 재질·색: 전체(아이보리 벽돌형 타일) 타일(#E6E2D3), 측면 세로 줄무늬 부조 패널 노출 콘크리트(#B8B5AA), 창 사이 흰 띠·캐노피 도장(페인트)(#F2F0EA)
- 창문 패턴: 아치 머리의 좁고 긴 세로창(층마다 흰 띠로 끊김) + 일부 사각 개별창
- 입구·계단: 서(도로 쪽) 짙은 갈색 아치 현관(박물관 'M' 로고 유리문), 위에 흰 캐노피 띠. 계단: 현관 앞 낮은 계단·난간
- 특징(기둥, 간판, 조형물 등): 아치 현관과 'M' 로고, 세로 줄무늬 부조 패널, 검은 주철 가로등
- 주변(나무, 바닥, 광장): 바닥 보도 빨간 벽돌색 블록+노란 점자블록, 빨간 자전거도로, 차도 아스팔트; 나무 화단에 원뿔형 향나무, 굽은 소나무 줄지어; 높낮이 남동쪽이 낮음(4.3m)
