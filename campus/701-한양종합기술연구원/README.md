## 1. 외관 메모 (사진 보고 정리)
- 전체 형태: 불규칙 — 대형(바닥 약 4,000㎡) 6층 연구동 — 석재 기단 위에 기둥으로 구획된 청록 유리 커튼월 상부, 꼭대기에 크게 내민 처마
- 층수·높이(눈대중): 약 6층 (대장/추천값은 표 0 참고)
- 지붕: flat, #3d4a55 — 확인 못함
- 외벽 재질·색: 베이지 화강석 #ddd6c8(저층부 기단·기둥), 유리 커튼월 #4f8fa6(고층부(청록 유리, 수평 멀리언)), 금속 패널 #3d4a55(처마·상부 띠)
- 창문 패턴: 기단부는 석재 벽에 작은 개별창, 상부는 원형 기둥 사이 청록 유리 커튼월
- 입구·계단: 남 — 'HIT 지하주차장' 차량 출입구(검은 간판) [지하1층]
- 특징(기둥, 간판, 조형물 등): 'HIT 지하주차장' 간판; 원형 흰 기둥이 유리면을 세로로 구획; 상부 진회색 대형 처마
- 주변(나무, 바닥, 광장): 소나무(굽은 노송) 여러 그루; 붉은 블록 보도, 아스팔트 도로; 주차장 진입로 양옆 곡선형 콘크리트 블록 옹벽(조경 화단); 동쪽이 낮음, 남쪽 도로에서 지하주차장으로 바로 진입
