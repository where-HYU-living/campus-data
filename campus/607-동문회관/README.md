## 1. 외관 메모 (사진 보고 정리)
- 전체 형태: ㄱ자 — 6층, 사선으로 꺾인 돌출 박스(베이창형 매스)가 계단식으로 반복되는 입면, 중앙 현관부에 평지붕 포치
- 층수·높이(눈대중): 약 6층 (대장/추천값은 표 0 참고)
- 지붕: flat, #d8d3c8 — 옥상 조경(나무가 위로 보임), 상부 'H Square' 로고 간판
- 외벽 재질·색: 베이지 화강석 #e3ddd2(전체), 유리 커튼월 #3d5560(1층 로비·창)
- 창문 패턴: 돌 외벽에 세로로 긴 개별창(2분할), 돌출 베이마다 측면 창
- 입구·계단: 서(도로 쪽) — 화강석 넓은 계단(약 8단) + 평지붕 캐노피 포치 + 유리 자동문 [1층]; 서(오른쪽) — 신한은행 지점 출입구 [1층] / 계단: 정면 폭넓은 화강석 계단, 양옆 스테인리스 난간
- 특징(기둥, 간판, 조형물 등): 현관 캐노피 위 '동문회관' 간판(파란 로고); 옥상부 'H Square'(웨딩홀) 로고; 1층 오른쪽 신한은행 'DIGILOG' 간판; 왼쪽 앞에 금속 지붕 흡연/휴게 쉘터
- 주변(나무, 바닥, 광장): 소나무 몇 그루, 회양목 생울타리; 앞마당 화강석 판석, 보도 붉은 벽돌 블록; 남쪽 화단 경계 낮은 벽돌 담; 도로보다 1층 바닥이 계단만큼(약 1.5m) 높음
  _(신뢰도 높음 — 자세한 값은 `appearance.json`)_
