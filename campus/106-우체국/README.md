## 1. 외관 메모 (사진 보고 정리)
- 전체 형태: 작은 단층~2층 건물로 추정(바닥 145㎡)
- 층수·높이(눈대중): 확인 못함
- 지붕: 확인 못함
- 외벽 재질·색: 확인 못함
- 창문 패턴: 확인 못함
- 입구·계단: 확인 못함. 계단: 근처 왕십리로→캠퍼스 계단(36m, 85단)
- 특징(기둥, 간판, 조형물 등): 확인 못함
- 주변(나무, 바닥, 광장): 바닥 보도 회색 블록, 북쪽 길 아스팔트+빨간 보행로; 나무 주변 큰 나무가 빽빽함(로드뷰에서 건물이 가려짐); 높낮이 남서쪽이 낮음, 경사 32.5%로 가파름
- 메모: 신뢰도 낮음 — 건물 외관 전체(사진·웹 모두 못 찾음)
