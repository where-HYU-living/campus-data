- 층수·높이(눈대중): 약 6층 (사진 눈대중)
- 지붕: mixed, 평지붕+가운데 박공(페디먼트), 코니스 위 피니얼 장식, 색 #B8B6B0 / 옥상: 코니스 난간 위 작은 장식 기둥(피니얼) 줄
- 외벽 재질·색: 전체(밝은 회색 석재) 베이지 화강석 #CFCDC7; 1층 큰 창(청록 유리) 유리 커튼월 #3E8C80; 오른쪽 상부 접힘판 부조 금속 패널 #D9D6CF
- 창문 패턴: 격자 개별창, 층마다 석재 창틀과 작은 삼각 창머리 장식, 1층은 기둥 사이 큰 청록 유리창 (창틀 #2E3A3A, 유리 #3E6A68)
