## 1. 외관 메모 (사진 보고 정리)
- 전체 형태: 해당 없음(건물 아님)
- 층수·높이(눈대중): 해당 없음
- 지붕: 해당 없음
- 외벽 재질·색: 확인 못함
- 창문 패턴: 해당 없음
- 입구·계단: 서(왕십리로 쪽) 보도에서 위로 올라가는 계단·에스컬레이터 출구, 평지붕 캐노피, 초록색 '한양대' 기둥 안내판, 버스정류장 옆; 동(캠퍼스 쪽) 2번 출구 = 104 애지문(유리 큐브)로 한양플라자 광장에 바로 나옴. 계단: 왕십리로 보도에서 캠퍼스(높은 쪽)로 올라가는 계단+에스컬레이터, 유리·금속 난간
- 특징(기둥, 간판, 조형물 등): 왕십리로 위를 가로지르는 짙은 회색 콘크리트 고가 구조물(보행/선로 구조물로 보임), 역·차량기지 쪽 긴 건물은 베이지·회색 사각 패널 외벽 + 가로 띠창, 초록 '한양대' 역 기둥 표지, 빨간 프레임 버스정류장
- 주변(나무, 바닥, 광장): 바닥 보도는 회색/분홍 콘크리트 블록, 차도 아스팔트(파란 버스전용선); 나무 보도 가로수(느티나무 등) 줄지어; 높낮이 도로면이 캠퍼스 광장보다 한 층가량 낮음 — 출구는 위로 올라가는 구조
- 메모: 신뢰도 낮음 — 출구 번호별 정확한 위치·개수, 고가 구조물이 보행육교인지 선로인지, 출구 캐노피 색
