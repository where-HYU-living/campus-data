## 1. 외관 메모 (사진 보고 정리)
- 전체 형태: 좌우 대칭 신고전주의 건물, 가운데 현관(포르티코) + 양 끝 날개
- 층수·높이(눈대중): 지상 4층 + 지붕층
- 지붕: **초록색 경사 지붕**, 작은 **삼각 지붕창** 여러 개, 양 끝 날개는 **흰 박공(삼각형 벽) + 아치 창**
- 외벽 재질·색: 밝은 베이지·회색 **화강석 블록**(거친 면)
- 창문 패턴: 층마다 규칙적인 세로형 창, 흰 창틀
- 입구·계단: 정면 가운데 **넓은 화강석 계단**
- 특징(기둥, 간판, 조형물 등): **흰 원기둥 6개**(2층 높이 이상), 위에 **부조가 있는 삼각 박공**, 2층 발코니 흰 난간
- 주변(나무, 바닥, 광장):
- ⚠️ (보강·정정) 위 메모(흰 원기둥 6개·초록 지붕)는 **101 역사관(구본관)** 외관으로 보임 — 위치(사자상 바로 동쪽)와 웹 설명(사자상은 구본관 앞, 2009 신본관은 구름다리로 연결)이 그쪽과 맞음
- (보강) **102 신본관 실제 외관**(2009, 6층): 가운데 **시계탑**(화강석 몸체 + 파란 유리 세로띠 + **초록 돔**), 좌우로 긴 날개
- (보강) 외벽 3단: 1~2층 **거친 베이지 화강석 기단**(가운데 큰 **아치 현관**) / 위층 **흰 석재 패널** + 가로 사각창 / 최상층 **파란 유리 띠**
- (보강) 지붕: 평지붕, 탑 위 초록 동판 돔·첨탑. 탑 상부에 '102' 번호판
- (보강) 주변: 앞은 넓은 계단+잔디, 회색 화강석 광장. 북쪽 길에서 **유리 구름다리**로 역사관과 연결
