# 한양대 서울캠퍼스 건물·랜드마크 자료실

건물마다 폴더 하나: `README.md`(외관 메모·사진 출처·건축물대장·모델링 상태) + `photos/` + (나중에) `ledger.json`.

- 목록 기준: **한양대 공식 '서울캠퍼스 건물 명칭 및 번호' 지도 (2026년 8월판, hanyang.ac.kr/map_seoul)** + 한양위키 '건물/영문명2017'(영문명, 인터넷 아카이브)
- 2026년 공식 지도에서 새로 확인: 213 구자겸기계관, 617 간호미래교육관, 619 의생명융합연구센터, 702·703 한양사이버대학교 1·2관, 707 행원파크, 809·810 제6·7학생생활관
- `N` 번호 폴더 = 건축물대장에만 있고 공식 지도에는 없는 이름 (옛 이름·한양여대·부속 건물 가능성, 확인 필요)
- 지도 위치는 OpenStreetMap 건물과 이름으로 연결 (`buildings.json`)

## 건물 디자인 정보는 어디서 얻나 (출처별 정리)
| 출처 | 얻는 정보 | 상태 |
|---|---|---|
| **웹 사진** (Bing 이미지, 위키미디어 공용, 한양대 학보 newshyu.com, Flickr, 유튜브 캠퍼스 걷기 영상) | 외관·색·재질·지붕·기둥·창문 | 사자상·본관·노천극장 진행. CC 라이선스 사진만 `photos/`에 저장, 나머지는 링크 |
| **한양위키 아카이브** (web.archive.org, 2026-09 서비스 종료) | 건물 번호·영문명·연혁·리모델링 이력 | 건물 목록·노천극장 연혁 확보 |
| **건축물대장 표제부** (공공데이터포털 API) | 층수, **높이**, **구조**(철근콘크리트 등), **지붕 구조**, 연면적, 건축면적, 사용승인일(지어진 해) | `tools/fetch-ledger.mjs` 준비 완료 — API 키 + 법정동코드 필요 |
| **건축물현황도 배치도** (세움터) | 건물 외곽 치수·배치 | 누구나 발급 가능, 동별 수작업 |
| **OpenStreetMap** | 바닥 윤곽, 일부 층수·높이, 출입구 | `buildings.json`에 연결 |
| 설계자·건축상 자료 (건축 잡지, 설계사무소 포트폴리오) | 설계 의도, 상세 도면 이미지 | 검색해 봤지만 아직 못 찾음 |
| **카카오맵 로드뷰** ⭐ | 거리에서 본 외관 (캠퍼스 안쪽까지, 2026년 7월 촬영) | 건물마다 **그 건물을 바라보는 링크 자동 생성** (`tools/make-roadview-links.mjs`, 61/69). 눈으로 참고만, 캡처 저장 안 함 |
| 네이버 지도 거리뷰 | 거리에서 본 외관 | Claude 브라우저 창에서는 안전 제한으로 열리지 않음 (사용자 브라우저에선 가능) |

## 건축물대장 자동 채우기
1. 공공데이터포털에서 '국토교통부_건축HUB_건축물대장정보 서비스' 활용신청 → 일반 인증키(Decoding) 발급
2. `tools/.env.example` 을 `tools/.env` 로 복사하고 키 입력
3. (자동) 처음 실행 때 행당동·사근동 법정동코드를 스스로 찾아 `tools/ledger.config.json` 에 저장
4. `node campus/tools/fetch-ledger.mjs` → 각 폴더에 `ledger.json` 생성, 못 맞춘 건물은 `_ledger/unmatched.json`
5. `node campus/tools/apply-ledger.mjs` → 별칭표(`tools/ledger-aliases.json`: 옛 이름→건물 번호, 확실/추정 구분)로 다시 연결. 부속시설·학교 밖 건물은 걸러내고 결과는 `_ledger/report.md`
   - 2026-11-07 결과: 원본 101건 → **51개 건물에 58건 연결**, 부속시설 27, 학교 밖 5, 남은 미연결 11
   - 2017 목록에 없던 **새 건물 15개**를 `N01~N15` 폴더로 추가 (신본관, 제4공학관, 제6·7학생생활관 등)
   - 연결된 높이는 3D 초안(`proto`)에 자동 반영 (34동)

## 건물 프로필 = 여러 출처를 한 건물에 쌓기
각 출처를 **그 출처에서 믿을 수 있는 기준**으로 우리 건물 목록에 붙인다. 이름이 틀린 출처도 버리지 않고 위치로 붙인다.

| 출처 | 연결 기준 | 주는 것 |
|---|---|---|
| 공식 캠퍼스 지도 (2026-08) | 번호 | 공식 번호·이름 |
| OpenStreetMap | 이름 | 바닥 윤곽, (일부) 층수·높이 태그 |
| 건축물대장 (공공데이터포털) | 이름·별칭표 | 층수·높이·구조·준공·층별 용도 |
| 브이월드 도로명주소건물 `LT_C_SPBD` | **위치** | 건물명·층수·도로명주소·건물관리번호 |
| 브이월드 건물통합정보 `LT_C_BLDGINFO` | **위치** | 정확한 도형 (이름표는 한 필지 문제로 신뢰 낮음) |
| 카카오 로드뷰 | 폴더 | 외관 사진 |

결과: 각 폴더 `profile.json` + README 맨 위 "0. 출처별 데이터" 표 (출처별 값과 **추천값**), 전체는 `profiles.json`

**다시 만드는 순서**
```bash
node campus/tools/apply-ledger.mjs          # 대장 ↔ 건물 (이름·별칭)
node campus/tools/fetch-ledger-extra.mjs    # 층별개요·건물ID 붙이기
node campus/tools/fetch-vworld-layer.mjs LT_C_SPBD
node campus/tools/fetch-vworld-layer.mjs LT_C_BLDGINFO
node campus/tools/fetch-site-data.mjs       # OSM 전체 태그(넓은 범위) + 지형 타일
node campus/tools/locate-buildings.mjs      # 카카오맵 장소 검색 → 위치 없는 건물에 OSM 윤곽 연결
node campus/tools/fix-locations.mjs         # 잘못 잡힌 검색 되돌리기 + 도로명주소건물 윤곽 보충
.venv/bin/python campus/tools/ngii-to-json.py  # 국토지리정보원 수치지도 → 2m 지형 격자·옹벽·계단·건물 (data/terrain/ngii/)
node campus/tools/build-site.mjs            # 건물별 지면 고도·경사·출입구·계단 → site.json, _site/
node campus/tools/build-profiles.mjs        # 출처별 데이터 모아서 프로필
```

**건물 폴더 파일**
| 파일 | 내용 | 만드는 것 |
|---|---|---|
| `profile.json` | 출처별 데이터 + 추천값 | build-profiles |
| `site.json` | 지면 고도, 땅 기울기, 출입구, 주변 계단·옹벽, 이웃 건물과 높낮이 | build-site |
| `appearance.json` | 지붕·외벽 재질·색(#hex)·창문·입구·주변 + 출처 | 조사 (사진·웹, `tools/APPEARANCE-BRIEF.md`) |
| `ledger.json` | 건축물대장 기록·층별 용도 | apply-ledger, fetch-ledger-extra |

**캠퍼스 전체 (`_site/`)**: `summary.md`(건물 고도 순위·큰 계단·평지), `stairs.json`, `open_areas.json`(운동장·코트·공원), `walls.json`, `kakao_places.json`
- 지형: 국토지리정보원 수치지도 등고선·표고점 → 2m 격자 (`data/terrain/ngii/dem.json`, 없으면 AWS 30m급으로 자동 대체). 수치지도 원본은 재배포 금지.
- 처음 한 번: `python3 -m venv .venv && .venv/bin/pip install pyshp pyproj numpy scipy` (저장소 루트)
