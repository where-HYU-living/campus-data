## 1. 외관 메모 (사진 보고 정리)
- 전체 형태: 광장 쪽으로 높은 상자형 5층. 정면 전체를 은색 금속 루버 격자 스크린이 감싸고, 1층은 뒤로 물린 유리 + 앞으로 내민 흰 캐노피. 서쪽(왕십리로)은 도로가 낮아 한 층 더 드러남
- 층수·높이(눈대중): 5층
- 지붕: flat / 확인 못함(루버 스크린 윗단이 옥상 난간 역할로 보임)
- 외벽 재질·색: 정면(동·남) 루버 스크린 금속 패널(#B9BDBF), 저층부 1층 유리 커튼월(#4A5560), 서쪽(왕십리로) 측면 사각 패널 타일(#C9C6BE)
- 창문 패턴: 정면은 루버 스크린 뒤 숨은 창, 서쪽은 가로 띠창
- 입구·계단: 동(한양플라자 광장) 1층 유리문 여러 개 + 흰 캐노피 아래 테라스(야외 테이블); 서(왕십리로) 도로 쪽 낮은 층 출입. 계단: 광장 쪽 계단 없음(평지), 서쪽 도로와는 한 층 높이차
- 특징(기둥, 간판, 조형물 등): 정면 위쪽 대형 현수막(파란색 대학평가 광고), 루버 위 파란 필기체 'Hanyang Plaza' 글씨, 왼쪽 위 '105' 번호판, 2003년 전면 리모델링, 2015년 1·2층 재단장(웹)
- 주변(나무, 바닥, 광장): 바닥 광장 회색 화강석 블록, 건물 앞 노란 띠; 나무 서쪽 도로변 가로수·생울타리; 높낮이 북서쪽이 낮음 — 광장(동)에서 1층, 왕십리로(서)에서 더 아래층
