## 1. 외관 메모 (사진 보고 정리)
- 전체 형태: 흰 상자형 7층 본동 + 계단실 탑 + 보일러동
- 층수·높이(눈대중): 약 7층
- 지붕: 평지붕, 꼭대기 '207' 번호판
- 외벽 재질·색: 흰 페인트(#E3E4E2)
- 창문 패턴: 작은 정사각 개별창 일렬, 계단실 탑은 뚫린 개구부
- 입구·계단: 남쪽 1층 주출입, 북쪽 대운동장 쪽 2.5·3층 출입(나무위키)
