## 1. 외관 메모 (사진 보고 정리)
- 전체 형태: 좁고 높은 직육면체 타워, 과학기술관과 모든 층이 붙어 있음(수평 증축)
- 층수·높이(눈대중): 지상 9층 + 지하 3층(나무위키), 사진상 9~10층
- 지붕: 평지붕, 상단에 '202' 번호판
- 외벽 재질·색: 밝은 회베이지 타일(#D4CFC6) 격자 파사드, 저층부 청록 유리(#4E8A86), 짙은 남색 유리 코어. ※2026 하반기 파란색 재도색설
- 창문 패턴: 깊게 판 정사각 개구부 격자
- 입구·계단: 북쪽 1층 현관(유리 포디움 아래), 남쪽 살곶이길 쪽 지하1층 출입
- 특징(기둥, 간판, 조형물 등): '202' 번호판, 저층부 '건축관' 글씨
- 주변(나무, 바닥, 광장): 남쪽 화강석 블록 화단 옹벽+소나무, 북쪽 경사 진입로
