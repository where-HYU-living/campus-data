# 건물 외관 조사 지침 (조사 에이전트용)

목표: 한양대 서울캠퍼스 3D 모델링(Three.js)에 쓸 건물 외관 정보를 건물 폴더마다 정리한다.
폴더: /Users/inter4259/maindesktop/chatatda-hanyang/campus/<폴더>/

## 건물마다 할 일
1. 먼저 읽기: `README.md`, `profile.json`(층수·높이·준공·구조), `site.json`(지면 고도·경사·출입구·주변 계단), `ledger.json`(있으면 층별 용도).
2. `photos/` 안 사진(roadview-*.jpg, commons-*.jpg)을 Read 도구로 직접 보고 관찰한다. 로드뷰는 길에서 건물 쪽을 본 화면이라 다른 건물이 찍혔을 수 있다 — 이름 간판·위치로 맞는지 판단하고, 아니면 "다른 건물로 보임"이라고 적는다.
   - 몇몇 신축 건물(213, 301, 611, 617, 619, 705, 707, 803, 806, 807, 809, 810, 904, 905)은 사진이 지금 저장되는 중일 수 있다. 사진이 없으면 마지막에 한 번 더 확인한다.
3. 웹 검색(WebSearch, 필요하면 WebFetch)으로 외관 사진·설명·기사를 찾는다. 검색어 예: "한양대 <건물명> 외관", "한양대학교 <건물명> 준공", "<건물명> 리모델링", 한양대 학보(newshyu.com), 건축 잡지/설계사무소 작품 소개. 웹 사진은 저장하지 말고 URL만 출처에 적는다.
4. `appearance.json` 작성 (아래 형식, 모르는 값은 null — 지어내지 말 것).
5. `README.md`의 "## 1. 외관 메모 (사진 보고 정리)" 섹션의 bullet 들을 채운다 (이미 내용이 있으면 지우지 말고 보강). 다른 섹션은 건드리지 않는다.

## 규칙
- 색은 사진에서 눈으로 본 대표색을 #hex로 (그늘·역광은 감안해 실제 재질 색으로).
- 담당 폴더 밖 파일은 수정하지 말 것. buildings.json, profiles.json, tools/ 는 건드리지 않는다.
- 끝나면 건물별 한 줄 요약(번호, 지붕, 주 외벽, 신뢰도, 특이사항)만 보고한다.
