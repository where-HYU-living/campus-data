- 층수·높이(눈대중): 약 5층 (사진 눈대중)
- 지붕: flat, 평지붕, 짙은 처마 끝, 색 #3E4246 / 옥상: 확인 못함
- 외벽 재질·색: 전체 도장(페인트) #F1F0EC; 창 사이 베이지 가로 띠 금속 패널 #C9BFA8; 오른쪽 위 계단실 유리 커튼월 #4E9AA0
- 창문 패턴: 격자 개별창(짙은 창틀), 창 아래마다 베이지 패널 띠 (창틀 #2C3438, 유리 #4E8A96)
- 입구·계단: 남동(주차장): 곡면 가림벽 뒤 외부 계단, 1층 출입문 [1층] / 계단: 곡면 벽 안쪽 외부 철제 계단. 건물 앞은 평탄 / 높낮이: 지면 평균 67.3m, 동쪽이 3.8m 낮음. 동쪽 도로보다 옹벽+비탈만큼(약 3~4m) 높음
- 특징(기둥, 간판, 조형물 등): 곡면 벽 '사범대학(별관)' 글씨; 상단 '506' 번호판; 원형 구멍 3개
