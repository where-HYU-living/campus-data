## 1. 외관 메모 (사진 보고 정리)
- 전체 형태: 7층 판상형, 서쪽 면에 흰 돌출 발코니가 세로로 반복, 옆에 회색 계단 코어 (위치는 804 서쪽 끝·유치원 쪽, 확정 아님)
- 층수·높이(눈대중): 지상 7층·지하 1층(공식). 대장 '제2학생생활관(B)'라면 25.2m
- 지붕: 평지붕으로 추정(사진에 안 보임)
- 외벽 재질·색: 흰 발코니(#ECECEA), 안쪽 벽·하부 짙은 회색(#5B5F65), 코어 회색(#9A9EA2)
- 창문 패턴: 발코니 안쪽으로 들어간 창, 1층 격자 방범창
- 입구·계단: 사진에 안 보임
- 특징(기둥, 간판, 조형물 등): 가로 줄무늬 난간의 돌출 발코니, 계단식으로 붙은 작은 회색 창 박스
- 주변(나무, 바닥, 광장): 앞 석재 무늬 옹벽(1.5~2m)+소나무, 아스팔트 주차장·자전거 거치대, 서쪽에 한양여대 부속유치원
