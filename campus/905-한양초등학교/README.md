## 1. 외관 메모 (사진 보고 정리)
- 전체 형태: 긴 본동에 오른쪽 날개가 꺾여 붙은 ㄱ자 교사동(약 103×50m 범위), 계단실 세로 띠 돌출
- 층수·높이(눈대중): 경사로 위 4개 층 + 아래 반지하(브이월드는 3층으로 표기)
- 지붕: 평지붕, 고전풍 난간형 파라펫과 작은 박공 장식
- 외벽 재질·색: 베이지 석재 패널(#D8CFC2), 계단실 세로 띠는 회청색 패턴 타일(#8E979C). 2006년 외부 리모델링
- 창문 패턴: 층마다 2~3칸 가로 교실창 반복, 짙은 회색 창틀
- 입구·계단: 동쪽 살곶이길에서 난간 달린 경사 브리지로 1층 현관(아치형 간판)
- 특징(기둥, 간판, 조형물 등): 아치 간판 현관, 회청 타일 띠, 노란 놀이기구
- 주변(나무, 바닥, 광장): 벽돌 보도, 소나무와 관목 화단, 동쪽이 낮은 경사(12.7m)
