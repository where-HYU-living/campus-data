## 1. 외관 메모 (사진 보고 정리)
- 전체 형태: 불규칙 — 74×79m 큰 사각 덩어리, 면마다 깊게 들어간 홈(세로 슬릿·상층 테라스 홈)으로 분절 (특이: 상층 깊은 테라스 홈, 세로 슬릿창)
- 층수·높이(눈대중): 약 6층 (사진 눈대중)
- 지붕: flat, 콘크리트 평지붕, 색 #B6B6B2 / 옥상: 확인 못함
- 외벽 재질·색: 전체(밝은 회색 석재 판 격자) 베이지 화강석 #CFCFCA; 창·1층 유리 유리 커튼월 #3A4248
- 창문 패턴: 석재 판 격자 안 작은 사각 개별창이 줄지어, 일부 세로 좁은 슬릿창, 1층은 큰 유리 (창틀 #5A5E62, 유리 #3A4248)
- 입구·계단: 남(높은 쪽): 주출입(70.1m) [1층] / 북(낮은 쪽): 서비스 출입(67.3m) [지하1층 추정] / 계단: OSM상 주변 계단 3개(15.5m 길이 단차 2m가 2m 거리, 9m 길이 단차 1.3~1.9m) / 높낮이: 지면 평균 68.8m(사자상 +23.5m), 북쪽이 5.7m 낮음. 주출입 70.1m와 서비스 67.3m 차이 약 3m — 북쪽에서 지하층이 반쯤 드러남
- 특징(기둥, 간판, 조형물 등): 석재 판 격자의 무거운 매스; 깊은 수평 홈이 그림자 띠를 만듦
- 주변(나무, 바닥, 광장): 옹벽·축대: 도로 쪽은 낮은 화단 턱 정도 / 바닥: 보도 붉은 벽돌, 도로 아스팔트(파랑·노랑 차선) / 나무: 도로변 소나무·벚나무, 관목 화단과 철쭉
