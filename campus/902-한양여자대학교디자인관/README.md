## 1. 외관 메모 (사진 보고 정리)
- 전체 형태: 일자형 — 살곶이길을 따라 남북으로 긴 고층 판상형 매스. 동쪽(도로) 면은 커튼월, 북쪽 끝은 석재 타일 면
- 층수·높이(눈대중): 약 10층 (사진 눈대중, 신뢰도 중간)
- 지붕: flat, 재질 미확인. 사진에서 안 보임
- 외벽 재질·색: 유리 커튼월 #2E8FC4(정면), 타일 #D0CEC8(측면), 금속 패널 #D9653F(정면), 붉은 벽돌 #A4553E(측면), 베이지 화강석 #C9C6C0(저층부)
- 창문 패턴: 동쪽 면: 청록색 가로 띠 커튼월 + 주황색 큰 사각 프레임 안 유리, 저층부는 회색 석재에 개별창. 북쪽 면: 회색 석재 타일에 격자 개별창(이중 사각창)
- 입구·계단: 서(캠퍼스 안쪽, 추정) OSM main 출입구(고도 27.2m). 사진에서 정문 확인 못함; 북 '한양여자대학교 PARKING' 표지가 있는 주차 출입부. 계단: 25m 안 계단 없음(site.json)
- 특징(기둥, 간판, 조형물 등): 동쪽 커튼월 위에 주황/테라코타색 큰 'ㄷ'자 프레임 장식; 북쪽 모서리 '한양여자대학교 PARKING' 녹색 글씨 간판; 살곶이길(동쪽) 가로에 바로 면함
- 주변(나무, 바닥, 광장): 살곶이길 가로수(은행나무 등)가 동쪽 면을 가림; 바닥 보도블록(회색·적색), 아스팔트 살곶이길; 축대 보도 화단 가장자리에 자연석 낮은 쌓기; 부지 안 5.6m 차이, 북동쪽(살곶이길 쪽)이 낮음
- 상세: `appearance.json` 참고
