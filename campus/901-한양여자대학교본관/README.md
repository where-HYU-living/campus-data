## 1. 외관 메모 (사진 보고 정리)
- 전체 형태: 불규칙 — 90×48m 대형 매스(OSM 바닥 1690㎡). 밝은 석재 프레임 안에 청색 유리 커튼월 면이 크게 들어간 고층부, 지하 3층(건축물대장)
- 층수·높이(눈대중): 약 7층 (사진 눈대중, 신뢰도 중간)
- 지붕: flat, (철근)콘크리트 평지붕(건축물대장). 최상층에 가로 루버/난간형 프레임이 보임(roadview-1 상단) — 자세한 설비는 안 보임
- 외벽 재질·색: 유리 커튼월 #6F93B8(정면), 베이지 화강석 #E3DDD2(전체)
- 창문 패턴: 청색 반사유리 커튼월(가로 멀리언 강조) + 석재면에 세로로 긴 개별창
- 입구·계단: 방향 미상 OSM상 main 출입구 1개(고도 27.5m)+service 3개. 사진에서 정문 형태는 확인 못함. 계단: 서쪽 사근동10길 쪽으로 화단 계단이 있고, 주변에 104m 길이(단차 약 13m) 긴 계단이 지나감(site.json)
- 특징(기둥, 간판, 조형물 등): 밝은 석재 + 청색 유리 커튼월의 2004년 준공 현대식 외관; 서쪽 골목의 클래식 가로등(검정 주물, 2등); 2011년 기사에 3개층 증축 계획 언급
- 주변(나무, 바닥, 광장): 소나무·활엽수가 건물 앞 화단을 촘촘히 가림; 바닥 아스팔트 도로 + 화강석 경계석, 장애인 주차 구역(청색 도장); 축대 서쪽 사근동10길 쪽 화단에 자연석 쌓기 축대(높이 1~2m); 부지 북쪽이 약 3.4m 낮음. 서쪽 골목(사근동10길)이 식품영양관(908)과의 사이로 오르막
- 상세: `appearance.json` 참고
