## 1. 외관 메모 (사진 보고 정리)
- 전체 형태: 거의 정사각(약 105×102m) 큰 경기장 상자. 아래 2층은 기둥이 받친 넓은 현관층, 가운데 흰 수평 띠(관람석층), 맨 위는 짙은 회색 골강판으로 덮인 상부 박스. 북서쪽 모서리에 흰 계단탑
- 층수·높이(눈대중): 5층
- 지붕: 확인 못함 / 상부 외벽은 짙은 회색 세로 골 금속판 / 확인 못함(대경간 철골 지붕)
- 외벽 재질·색: 중간 수평 띠·계단탑(흰색) 노출 콘크리트(#E2E3E1), 고층부(상부 박스 세로 골강판) 금속 패널(#5A6268), 저층부 현관층 유리 유리 커튼월(#2E3338)
- 창문 패턴: 상부 박스 아래 가늘고 긴 띠창, 현관층은 큰 유리면(짙은 프레임 격자)
- 입구·계단: 서 회색 사각 기둥 열 아래 넓은 계단 + 유리문 여러 개, 위 띠에 '올림픽체육관' 큰 흰 글씨; 북서 흰 계단탑 쪽 출입구, 앞 넓은 계단 광장. 계단: 정면 앞 넓고 낮은 화강석 계단(5~6단), 북서쪽에도 넓은 계단(약 10단)
- 특징(기둥, 간판, 조형물 등): '올림픽체육관' 큰 글씨 사인 띠, 왼쪽 위 '306' 번호판, 1988 서울올림픽 배구 경기장(웹, 1986년 완공으로 소개 — 대장 사용승인 1993)
- 주변(나무, 바닥, 광장): 바닥 앞마당: 회색·흰 사각 타일 패턴 포장, 도로 아스팔트(노란 횡단보도, 빨간 보행띠); 나무 북서쪽에 소나무·관목, 오른쪽 가로수; 높낮이 남동쪽이 낮음(윤곽 안 22.8m 차) — 정면(서)은 광장 높이, 뒤로 갈수록 지하층이 드러남
